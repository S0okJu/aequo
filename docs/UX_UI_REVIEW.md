# UX/UI 점검 — 2026-11-17

## 평가

회색 표면, 파란 강조색, 공통 아이콘과 둥근 모서리는 일관적이다. 피드 탐색 → 글 목록 → 본문 → AI의 정보 위계도 명확하다. 기존 방향을 유지하고 창 크기 변화, 빈 화면, 버튼 대비와 키보드 동작에서 발견된 불일치를 보정했다.

## 반영한 수정

| 영역 | 발견한 문제 | 수정 |
| --- | --- | --- |
| 패널 배치 | 본문·AI 너비 계산에서 사이드바 구분선 6px 누락 | 모든 구분선 너비를 계산에 포함 |
| 창 크기 변경 | 창을 줄였다가 넓히면 본문·AI의 좁아진 너비가 고정되어 목록만 확대 | 선호 너비와 현재 표시 너비를 분리해 넓은 창에서 자동 복구 |
| 패널 전환 | 전환 중 좁아진 패널의 내용이 인접 영역으로 노출될 가능성 | 본문·AI 패널의 넘치는 내용 차단, 전환 시간 토큰 공유 |
| 리사이즈 | 포인터 캡처를 잃으면 드래그 상태가 남을 수 있음 | 캡처 해제 시 상태 정리, 읽기 패널의 접근성 최소 너비를 실제 320px와 일치 |
| 본문 | 창 전체 너비에 따라 제목 크기와 여백이 결정됨, 좁은 패널에서 제목과 버튼이 공간 경쟁 | 패널 너비 기준으로 크기 조정, 420px 이하에서 버튼 행 분리 |
| 빈 화면 | 글 목록은 상단에 몰리고 AI 안내는 헤더 때문에 아래로 밀림 | 각 패널의 남은 공간 안에서 중앙 정렬 |
| 색상 | 다크 모드의 연한 파란 버튼과 흰 글자 대비 부족, 성공 색상 개별 지정 | 주요·삭제 버튼의 테마별 전경색과 성공 색상을 공통 토큰으로 통합 |
| 공통 컨트롤 | 피드 추가 폼의 기본 시스템 글꼴, 팝오버 그림자 차이 | 폼 글꼴 상속, 팝오버·토스트 그림자 통일 |
| 별표 | 작은 클릭 영역, Enter/Space가 글 카드로 전파됨 | 28px 영역 제공, 카드 자체의 키 입력만 글 열기로 처리 |
| 모션 | 모션 감소 설정에서 회전·강조·부드러운 스크롤 일부 유지 | 전역 애니메이션·전환 해제 및 메모 이동 시 즉시 스크롤 |
| 비동기 표시 | AI 패널을 처음 불러올 때 빈 영역 표시 | 로딩 상태 제공 |
| 주석 도구 | 선택 도구의 위치 계산 크기가 실제 렌더링 크기와 다름 | 도구 크기에 맞춰 위치 계산 |
| 삭제 확인 | 공통 버튼 규칙의 우선순위로 삭제 강조색이 가려질 수 있음 | 삭제 확인 스타일의 선택자 우선순위 보정 |

## 검증

- `pnpm check`: 오류·경고 없음.
- `pnpm test`: 7개 파일, 48개 테스트 통과. 별표 버튼의 키 입력과 글 열기 분리 회귀 테스트 포함.
- `pnpm exec eslint src`: 통과.
- `pnpm build`: 통과.
- 샘플 Tauri 응답을 사용하는 로컬 Chromium 화면 검증: 1100·1360·1920 × 850px, 라이트·다크 모드의 패널 경계와 가로 넘침, AI 열기·닫기, 읽기 패널 닫기, 빈 목록, 설정 화면 4개 탭, 모션 감소 설정.

네이티브 Tauri WebView와 실제 피드·AI 서비스 연동은 이번 화면 검증의 범위에 포함하지 않았다. 앱의 최소 창 너비인 1100px 이상을 기준으로 평가했다.
